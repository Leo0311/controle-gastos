## Rollback da API (se o build ou o restart falhar)

```bash
cd ~/controle-gastos
git checkout <SHA_ANOTADO_ACIMA>
cd controle-gastos-api && ./mvnw clean package -DskipTests
sudo systemctl restart controle-gastos
# depois: git checkout master  (pra não ficar em detached HEAD)
```

O frontend não tem rollback de 1 clique (Render Static Site), mas com a API na
versão nova ele funciona; e com a API revertida, a tela de Gastos volta a
quebrar (C1). Ou seja: **se precisar reverter, reverta os dois** — `git revert`
dos 7 commits na `master` + push (frontend volta sozinho) + rebuild da API.
